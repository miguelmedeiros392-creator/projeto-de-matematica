MATEMÁTICA PARA A INCLUSÃO

Site educativo e interativo — Guia de instalação e personalização

📂 COMO ABRIR O PROJETO
Extraia o arquivo ZIP em uma pasta do seu computador.
Abra o Visual Studio Code.
Selecione Arquivo → Abrir Pasta e escolha a pasta do projeto.
Verifique se os arquivos index.html, style.css e script.js estão na mesma pasta.
Abra o arquivo index.html diretamente no navegador ou utilize a extensão Live Server para visualizar o site.
🎨 COMO PERSONALIZAR O SITE

Você pode adaptar o conteúdo de acordo com a identidade da equipe e as necessidades do projeto.

Integrantes e orientador: no arquivo index.html, substitua [Nome dos integrantes] e [Nome do orientador] pelos nomes correspondentes.
Galeria de fotos: os três quadros disponíveis são espaços reservados. Para inserir fotos reais, substitua cada elemento div.gallery-placeholder por uma imagem, por exemplo:

<img src="assets/foto1.jpg" alt="Descrição da foto">

Salve as imagens na pasta assets e, se necessário, adicione ao style.css:

.gallery img { width: 100%; height: 225px; object-fit: cover; border-radius: 16px; }

Textos e informações: edite diretamente o conteúdo do arquivo index.html.
Cores e aparência: personalize as variáveis de cores localizadas no início do arquivo style.css.
Produtos e preços demonstrativos: faça as alterações no objeto produtosDemo, localizado no arquivo script.js.
♿ ACESSIBILIDADE E RECURSOS

O projeto tem como objetivo demonstrar como a matemática pode contribuir para a inclusão e a acessibilidade no cotidiano.

Entre os recursos e propostas apresentados estão:

Recursos de leitura por voz.
Propostas de identificação de produtos em Braille.
Utilização de QR Codes para facilitar o acesso às informações.
Etiquetas acessíveis para identificação de produtos.
Simulação de carrinho de compras e apresentação de preços.
⚠️ INFORMAÇÕES IMPORTANTES
Os preços exibidos no site são fictícios e possuem finalidade exclusivamente demonstrativa.
Os recursos de Braille, QR Code e etiquetas acessíveis são propostas de soluções inclusivas, não instalações já realizadas.
O carrinho de compras funciona temporariamente na memória da página. Ao atualizar o site, os itens selecionados serão removidos.
A funcionalidade de leitura por voz depende da compatibilidade e do suporte oferecidos pelo navegador e pelo dispositivo.
O projeto não depende de bibliotecas externas nem de conexão com a internet para funcionar.
